Help & documentation

How to use the app safely.

Workflow

  • Choose a specialty.
  • Add leads and fit scores.
  • Enter only benchmark data you have rights to use.
  • Track negotiation changes in History.
  • Print/share an attorney-ready summary.

Shortcuts

  • Ctrl + N: new lead
  • Ctrl + B: benchmark
  • Ctrl + E: export/share
  • Esc: close/back

Security

  • XSS sanitization, schema validation, checksum verification, storage error alerts, and optional encryption are included.
  • This static file uses a CSP meta policy; production hosting should also set HTTP CSP headers.
